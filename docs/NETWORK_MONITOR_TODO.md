# 网络监测（第一步）

范围：三个来源共享的实际请求监测、异常低频诊断、管理页展示。
本阶段不改变代理分配、请求重试策略、失败台账或检查点规则。

- [x] 公共监测：按来源 / 目标域名 / 代理线路统计 5 分钟窗口，区分请求尝试与最终结果。
- [x] 诊断日志：线路、单次网络耗时、curl 错误码及脱敏错误摘要。
- [x] 连续 3 次网络失败触发诊断；原线路空闲后执行，至少间隔 60 秒，遵守限速。
- [x] 受鉴权保护的状态 API、管理页线路状态和过期数据提示。
- [x] 离线故障 / 恢复 / 并发 / 脱敏 / API 与页面逻辑回归。
- [ ] 桌面与移动端视觉验收：浏览器工具返回 `Codex auth token is unavailable`，环境阻塞。
- [x] 使用说明与验证结果：见 `docs/NETWORK_MONITOR.md`。

监测为当前进程内状态，重启后重新采样；异常 / 恢复事件写入现有日志。
网络诊断失败不能当作站点限流，也不能代表资源不存在。
