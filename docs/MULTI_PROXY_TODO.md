# 通用多代理会话与补抓可靠性

用户已于 2026-09-09 确认实施，覆盖 sehuatang、javbee、x1080x。

## 边界

- 一个代理地址（含端口）就是一条固定线路；不探测 IP、不控制 Clash、不维护节点信息、不自动切换代理。
- 公共层负责常驻会话、独立 Cookie/UA、CF 适配、限速、冷却、并发和请求去重；来源只保留页面解析与站点特有验证。
- 单进程多会话；同一来源跨进程互斥要求共享 data 目录。无需 Redis、分布式任务租约。
- 补抓限流重试原目标；成功数据及时保存；失败台账不能可靠写入时不推进检查点。
- 不执行生产补抓、部署或清理历史重复数据；不改其他工作树文件。
